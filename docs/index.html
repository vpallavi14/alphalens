The problem

Retail investors are overwhelmed by financial data. Hundreds of tickers, daily news cycles, earnings reports, social media sentiment — it is impossible to manually track everything. Existing tools either show raw data without insight, or charge premium fees for AI-driven analysis.

AlphaLens solves this by building a fully automated intelligence pipeline that scrapes financial news daily, extracts sentiment signals via NLP, scores stocks using ML models, detects anomalies, and generates structured buy/sell/hold investment briefs — all delivered through a clean dashboard.

02

Architecture

The platform follows a serverless, event-driven architecture on AWS. Data flows from external APIs through processing Lambda functions into DynamoDB, then to the Next.js frontend via API Gateway.

External APIs (Yahoo Finance, News, Social) | v +---------------------------+ | EventBridge Scheduler | Daily automated triggers +------------+--------------+ v +---------------------------+ | AWS Lambda Functions | Python processing layer | [Scraper] [Scorer] [LLM] | +------------+--------------+ v +---------------------------+ | DynamoDB + S3 | Data storage layer +------------+--------------+ v +---------------------------+ | API Gateway | REST API layer +------------+--------------+ v +---------------------------+ | Next.js Dashboard | React frontend | (AWS Amplify) | +---------------------------+ v +---------------------------+ | Cognito Auth | User authentication +---------------------------+
03

The intelligence pipeline

The system runs a multi-stage pipeline daily via EventBridge, processing market data through four stages before delivering insights to users.

1
Data Collection & Scraping
Lambda functions pull daily stock data, financial news, and social media signals from external APIs. Raw data is stored in S3 for historical analysis and fed into the processing pipeline.
2
ML Scoring & Anomaly Detection
Scikit-learn models compute an AlphaScore for each stock based on technical indicators, momentum, and historical patterns. Anomaly detection flags unusual price movements or volume spikes that warrant attention.
3
NLP Sentiment Extraction
Financial news and social signals are processed through sentiment analysis to extract bullish/bearish signals. These feed into a Social Score that augments the ML-based AlphaScore.
4
LLM Brief Generation
AWS Bedrock generates structured investment briefs synthesizing the ML scores, sentiment signals, and anomaly flags into actionable buy/sell/hold recommendations with supporting reasoning.

05

AWS architecture decisions

ServiceRoleWhy this choice
LambdaAll backend processingServerless, pay-per-invocation, auto-scales. No servers to manage for a pipeline that runs once daily.
DynamoDBStock data, scores, watchlistsKey-value lookups by ticker are the primary access pattern. Sub-millisecond reads at any scale.
S3Raw data, historical archivesCheapest storage for large JSON/CSV dumps from daily scraping. Feeds into Lambda for processing.
EventBridgeDaily pipeline schedulerCron-based triggers for the scraping and scoring pipeline. No polling, no always-on compute.
BedrockLLM brief generationManaged LLM access without self-hosting models. Pay per token, no GPU provisioning.
CognitoUser authManaged auth with JWT tokens. Handles signup, login, password reset without custom auth code.
API GatewayREST APIRoutes frontend requests to Lambda functions. Handles CORS, throttling, and auth validation.
AmplifyFrontend hostingCI/CD for Next.js. Push to GitHub and the dashboard auto-deploys.
